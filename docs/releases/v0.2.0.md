First public release.

- Channels for new series, this week's episodes, popular and top-rated shows, each streaming service and each genre, with channel up/down and a full channel guide.
- Search by name: SELECT opens an on-screen keyboard and CH 01 tunes to the matches. The last five searches are kept.
- Show details with IMDb, Rotten Tomatoes, Metacritic and TMDB scores, status and next air date, seasons, cast, services, and a trailer QR code.
- Order into Sonarr: new episodes only, every episode, chosen seasons or chosen episodes. Shows already in Sonarr are marked, and ordering them again changes what's monitored.
- Borrows TMDB and OMDb keys from Rewind when it's installed.
